# Pokémon Landing Page

A simple and responsive Pokémon-themed landing page built using **HTML** and **CSS**. The page showcases the Generation I Pokémon **Pikachu** with a modern UI, gradient background, custom typography, and Font Awesome icons. :contentReference[oaicite:0]{index=0}

## 📌 Features

- Pokémon-themed landing page
- Modern yellow gradient background
- Responsive layout
- Font Awesome menu icon
- Google Poppins font
- Large Pokémon image display
- Navigation indicator dots
- Clean and minimal design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
- Font Awesome Icons

## 🚀 How to Run

1. Download or clone the project.
2. Make sure all image files (`Pikachu.png` and `pngegg.png`) are in the project folder.
3. Open `index.html` in any modern web browser.

No installation or server setup is required.

## 🎨 Design Overview

- Left section displays:
  - Pokémon generation
  - Pokémon name
  - Description
  - Page indicator
- Right section displays:
  - Large Pikachu image
- Background uses a two-tone yellow gradient for a Pokémon-inspired look. :contentReference[oaicite:1]{index=1}
